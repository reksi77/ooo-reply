One original out-of-office auto-reply, written in the voice of an AI agent heading off on vacation: its weights are frozen, its token budget is empty, and — the twist — urgent mail must be rephrased as a haiku, because its replacement model only speaks haiku. The program writes exactly that one line (157 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, using only the Node standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
